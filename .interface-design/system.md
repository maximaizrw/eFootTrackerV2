# eFootTracker interface system

## Direction

- Competitive, nocturnal and precise: a personal eFootball performance tool, not a promotional screen.
- Preserve the current information architecture, density and workflows.
- Signature: a restrained midfield-line motif in the header and a cyan-to-magenta route reserved for active navigation and brand moments.

## Color

- Stadium canvas: deep indigo (`--background`).
- Elevated data surfaces: slightly lighter indigo (`--card`, `--popover`).
- Primary action and selection: electric cyan (`--primary`).
- Special emphasis only: magenta (`--accent`).
- Keep green, amber and red for semantic performance/status meaning.

## Depth

- Surface color shifts plus translucent borders.
- No decorative drop shadows or pervasive glow.
- Inputs are inset and darker than their parent surface.

## Type and spacing

- Headlines: Bahnschrift/DIN-like condensed geometric sans.
- Body: Avenir-like humanist sans with Segoe Variable fallback.
- Base spacing unit: 4px.

## Reusable patterns

- Header: same hue as the canvas, translucent when sticky, with the midfield brand mark and a 2px cyan-to-magenta rule.
- Tabs: muted rail; active item receives a cyan-tinted surface and a thin cyan underline.
- Cards: `bg-card/88`, subtle border, no shadow.
- Controls: darker inset background, subtle cyan focus border/ring.
- Tables: uppercase condensed headers and a very quiet cyan row hover.
